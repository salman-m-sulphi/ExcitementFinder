# Reviewing moments with the player

Click any numbered moment to start playback with your configured lead-in. The player shows **Moment #24**, for example, only while the playhead is inside that detected event. The number clears at its detected end, even when export tail is enabled. Playback continues normally. If playback reaches another detected event, its number appears automatically. The same moment is highlighted in the list. Changing the ranking or event threshold updates the displayed numbering to match the current list.

## Bottom-right player

Scrolling past the main player docks that same player at the bottom-right. It keeps its position, sound, controls, and moment label. **Back to player** returns to its original position. **×** hides the corner player; clicking a moment shows it again. Scrolling back to the main player restores the normal layout.

## Separate floating window

Choose **Floating window**. In the Windows app this opens a resizable window that stays above other applications. Playback transfers at its current position; the main player stays silent. Moment labels, playback speed, volume, and pause state transfer with it. You can click another moment in the main app while the floating window is open.

Choose **Return to app**, **Bring playback back**, or close the floating window with its Windows **X** to continue in the app. A separate browser window is used when running the website in a browser; allow local pop-ups if prompted. Browser windows follow the browser's own window and foreground rules, rather than the Windows app's always-on-top behavior.

## Fullscreen

Use the player's **Fullscreen** button, including inside the floating window. The moment number remains over the video. Press **Escape** or **Exit fullscreen** to return. Double-clicking the video also toggles fullscreen. Closing the main app closes its floating player and local engine.

Manual In/Out preview still pauses at the manual out point. Ordinary moment playback continues past detected event ends.
